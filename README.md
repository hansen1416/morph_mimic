# MorphMimic

Project page for "Morphology-Conditioned Physics-Based Motion Imitation Across 128 Body
Shapes" (model name: MorphMimic). Static HTML/CSS only, deliberately kept separate from the
research codebase at [hansen1416/ProtoMotions](https://github.com/hansen1416/ProtoMotions).

Preview locally: open `index.html` directly in a browser, no build step needed.

Deploy: push to `main` and enable GitHub Pages (Settings -> Pages -> Deploy from branch ->
`main` / root). Repo slug: `morph_mimic` (display name stays "MorphMimic"). Will be served at
`hansen1416.github.io/morph_mimic`.
