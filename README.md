# MorphMimic

Static project page for "Morphology-Conditioned Physics-Based Motion Imitation
Across 128 Body Shapes". Research code: https://github.com/hansen1416/ProtoMotions.

Open index.html locally or serve this directory with a static HTTP server.
GitHub Pages deploys from main at https://hansen1416.github.io/morph_mimic/.

## Evidence update — 11 October 2026

The page follows RQ1 shared tracking, RQ2 unseen-body transfer, and RQ3 network
and reference-quality comparisons. The old 32-body study is removed entirely.
Inside/outside results use the 9 October unseen_shapes_v2 evaluation, with 233
training identities × 128 unseen bodies per panel. Trained-body videos are
illustrations; they are not new unseen-body or reference-overlay comparisons.

The manuscript source is maintained separately in ProtoMotions/paper-draft/review.tex.
Tables mirror its headline populations, checkpoint comparison, three-seed
architecture results, reference audit and source-backed capability comparison.
Changes in checkpoint training duration and motion coverage are confounded.
